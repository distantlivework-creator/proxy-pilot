# Proxy Pilot for Android

Нативный помощник для официального Telegram без регистрации и без входа в
Telegram внутри Proxy Pilot.

## Как это работает

1. Приложение получает публичный каталог Proxy Pilot.
2. Телефон сам делает две короткие TCP-проверки каждого адреса из текущей сети.
3. На экране остаются все адреса, ответившие хотя бы один раз.
4. Пользователь выбирает любой зелёный адрес и подтверждает добавление уже в
   официальном Telegram.
5. Новые ссылки из канала можно передать вручную: в Telegram нажать
   «Поделиться» → Proxy Pilot. Из сообщения извлекаются все MTProto-ссылки.
6. Адреса и результаты сохраняются в локальном пуле телефона. Один временный
   сбой не удаляет недавно работавший маршрут: он становится жёлтым и остаётся
   для следующих проверок.
7. При переходе между Wi-Fi и мобильной сетью сохранённый пул проверяется снова.
8. Если публичный каталог временно недоступен, приложение использует последний
   локальный пул вместо пустого экрана.

Приложение не читает историю, каналы или переписку и не получает Telegram-сессию.
Поэтому ему не требуются номер телефона, `api_id`, `api_hash` или привязка к
аккаунту владельца проекта.

## Граница локальной проверки

Зелёный статус подтверждает, что телефон смог открыть сетевой маршрут до
прокси. Публичный каталог перед публикацией проходит отдельную серверную
MTProto-проверку. Окончательное подключение конкретного пользователя всегда
подтверждает официальный Telegram.

Жёлтый сохранённый маршрут означает, что он работал недавно, но не ответил в
текущей проверке. Кнопка добавления для него временно недоступна. После трёх
неудачных раундов он скрывается с главного экрана, но история не стирается и
может быть восстановлена успешной проверкой в другой сети.

## Сборка и тесты

- JDK 17
- Android SDK 36
- Android 6.0+ (`minSdk 23`)

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
./gradlew :app:connectedDebugAndroidTest
```

CI собирает APK и запускает реальный экранный сценарий на Android Emulator.
