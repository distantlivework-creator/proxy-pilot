# Proxy Pilot — Android, iPhone, macOS и Windows

Универсальная PWA с максимально простым интерфейсом в духе Outline: она собирает публичные MTProto proxy-ссылки, проверяет их и помогает добавить лучший вариант в Telegram на Android, iPhone, macOS и Windows.

**Рабочая PWA:** <https://distantlivework-creator.github.io/proxy-pilot/>

## Бесплатный тест без VPS и карты

Режим GitHub Pages не требует постоянно запущенного сервера:

- GitHub Actions каждые 15 минут читает публичные источники из `sources.txt`;
- извлекает и удаляет дубли MTProto-ссылок;
- дважды проверяет реальное прохождение MTProto-трафика до Telegram;
- учитывает историю успешных циклов и разнообразие операторов;
- публикует до 12 подтверждённых вариантов в `site/data/proxies.json`;
- PWA показывает самый быстрый и открывает штатный экран Telegram.

Страница распределяет посетителей между верхними вариантами, запоминает неудачные прокси на 24 часа и ведёт через настройку трёх резервов. Встроенная самодиагностика приостанавливает новые подключения, если подтверждённых резервов осталось меньше трёх, не мешая уже подключённым пользователям. GitHub Pages не сообщает странице точное число одновременных посетителей, поэтому интерфейс честно не изображает недоступный «счётчик мест».

Автоматизация находится в `.github/workflows/deploy-pages.yml`. Если в очередной проверке не осталось ни одного доступного прокси, развёртывание останавливается, и у пользователей остаётся предыдущий каталог.

Локальная сборка каталога:

```bash
python scripts/build_static_site.py
python scripts/update_catalog.py
python -m http.server 8080 --directory site
```

Публичные прокси надо считать недоверенными: их операторы видят IP-адрес и факт использования Telegram, хотя содержимое трафика остаётся зашифрованным.

## Универсальное приложение (рекомендуется)

Главная страница backend — это PWA. Она работает в браузере и устанавливается как отдельное приложение:

- Android: Chrome → «Установить приложение»;
- iPhone/iPad: Safari → «Поделиться» → «На экран Домой»;
- macOS: Safari → «Добавить в Dock» либо Chrome → «Установить Proxy Pilot»;
- Windows: Edge/Chrome → значок установки в адресной строке.

Для установки и service worker в локальной сети браузеру потребуется HTTPS. Исключение — `localhost` во время разработки. После установки последний экран доступен офлайн, а проверка обновится при появлении сети.

Это не системный VPN и приложение не меняет сетевой трафик других программ. Оно управляет только MTProto-прокси для Telegram через поддерживаемые Telegram ссылки.

## Нативное приложение для Android

Проект находится в `android/` и работает на Android 6.0 или новее. Аккаунт Proxy Pilot, номер телефона, вход в Telegram, `api_id` и `api_hash` не нужны.

Приложение:

- получает общий каталог, уже проверенный серверной MTProto-проверкой;
- с самого телефона дважды проверяет сетевой маршрут до каждого адреса;
- сохраняет все ответившие адреса, а не только самый быстрый;
- открывает выбранный адрес на штатном экране официального Telegram;
- принимает обычное Telegram-сообщение через «Поделиться» → Proxy Pilot, извлекает из него все MTProto-ссылки и проверяет их локально;
- содержит короткую пошаговую инструкцию и честно объясняет границу проверки.

Зелёный статус означает, что TCP-маршрут доступен из текущей сети телефона. Это полезная локальная проверка, но окончательное MTProto-подключение подтверждает официальный Telegram. Приложение не читает каналы и переписку автоматически: пользователь сам передаёт выбранное сообщение системной кнопкой «Поделиться».

## Серверная/PWA-версия

- читать публичные и доступные аккаунту приватные каналы через Telegram user API;
- распознавать `t.me/proxy`, `telegram.me/proxy` и `tg://proxy` ссылки;
- выполнять реальную проверку соединения с Telegram через MTProto (если заданы API credentials);
- ранжировать рабочие прокси по задержке;
- после нескольких последовательных сбоев убирать прокси из активного списка;
- открывать лучший прокси в Telegram через официальный deep link;
- повторять проверку в фоне.

Важно: публичный Telegram API не позволяет стороннему процессу молча менять настройки официального Telegram Desktop/Android/iOS. Кнопка открывает штатный экран добавления прокси. Полная автоматизация возможна в отдельном клиенте на TDLib — его настройки прокси TDLib разрешает менять программно.

## Запуск

Требуется Python 3.10+ (в текущем коде используется современный синтаксис типов).

```bash
cd mtproxy-pilot
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
```

Получите собственные `api_id` и `api_hash` на <https://my.telegram.org>, заполните `.env`, укажите каналы через запятую и один раз авторизуйте сессию:

```bash
python -m app.telegram_login
```

Запустите панель:

```bash
uvicorn app.main:app --reload
```

Откройте <http://127.0.0.1:8000>. Если credentials пока не заполнены, можно вручную добавить proxy-ссылку; проверка будет только на доступность TCP-порта.

## Безопасность

- `.env`, Telegram session и локальная база исключены из Git.
- Используйте каналы и прокси, которым доверяете: оператор прокси видит ваш IP и факт подключения, хотя содержимое Telegram-трафика шифруется.
- Не публикуйте `api_hash` и файл `.session`.
